## Destination

明确并记录一个可实施的 Astro 中文个人技术笔记博客方案：纸张质感的阅读体验、暗色模式、Markdown/MDX 写作、分类与标签、RSS，以及部署到 GitHub Pages 并绑定 `blog.loliking.com`。

## Notes

这是一个规划地图，不在本地图中直接搭建网站。优先保证中文技术文章的阅读与长期维护体验；每次推进决策票时使用 Wayfinder 与 grilling 流程。静态站首版不含评论、站内搜索或启用中的第三方统计；社交入口和统计配置仅预留位置。

## Decisions so far

- [定义内容与信息模型](issues/01-define-the-content-and-information-model.md) — 以 Content Collection 统一管理 Markdown/MDX，并锁定稳定 slug、受控分类、规范化标签、图片无障碍与共享发布过滤规则。

## Not yet specified

- 文章积累后是否需要系列专题、站内搜索与访问统计，以及各自的具体实现选择。
- 纸张质感在组件、纹理、排版和暗色模式中的具体表达，需在视觉草案后细化。
- GitHub Pages 发布环境确认后，`blog` 子域名的 DNS 记录及仓库设置的具体操作。
- 首批分类、标签、社交账号、联系渠道与“关于我”页面的实际文案。

## Out of scope

- 首版的评论系统、用户账号与内容审核。
- 首版的内容管理系统、站内搜索和启用中的第三方访问统计。
